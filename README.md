PROJECT TITLE: Simple C++ Arithmetic Program

DESCRIPTION:
This program demonstrates a simple modular C++ application that performs basic arithmetic operations (addition and subtraction) using separate header and source files.

ENTRY FILE:
main.cpp (contains the main function)

HOW TO COMPILE AND RUN:

Using g++ (Linux/Mac/WSL):
1. Open terminal in project folder
2. Compile using:
   g++ main.cpp utils.cpp -o program
3. Run:
   ./program

Using Windows (MinGW):
1. Open Command Prompt in project folder
2. Compile:
   g++ main.cpp utils.cpp -o program.exe
3. Run:
   program.exe

NOTES:
- Ensure all files are in the same directory before compiling.
- main.cpp is the entry point of the program.
